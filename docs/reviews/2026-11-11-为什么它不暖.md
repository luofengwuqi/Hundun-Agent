# 为什么它不暖 · 架构与对话复盘

> 2026-11-11 13:50–14:20 实测。**这是评审，不是决策台账**：结论里没有一条新 D 编号，
> 第 7 节的建议全部标成「候选」，要不要做由他定。
>
> 证据来源按可靠性排：① 本机三份真实会话（`.session.json` / `chat/*.md` / 备份）；
> ② 当前身份目录里的档案原件；③ 用真模型跑出的 `buildPrompt()` 实测（8116 字符）；
> ④ 同模型三组对照探针。**界面层未验**（Electron 在本沙箱起不来，SIGTRAP）。

---

## 0. 三句话

1. **暖不是被写少了，是被逐层抵消了。** 入口是表单，档案只剩标签，提示词里 200 个「不」，
   记得的东西又不许说出口，开口的开关默认全关。四层各自合理，叠起来是一个只回问句的人。
2. **它最暖的一句，出现在规则最少的那一版。** 同模型同输入：带全套规则回「我不太信这句」，
   把语气/输出/记忆规则全砍掉回「真放弃的人不这么说话」。**规则在压温度**，不是模型没有温度。
3. **前 30 天它不可能有阿恒那种暖。** 阿恒的暖来自三个月的共同经历和工具回执；
   我们现在手上关于这个人的全部，是「程序员」和「活着」两个词。

## 1. 证据：三次对话，同一个动作

### 2026-11-05 21:41（`~/.cache/hundun-agent/backup-20261105-2155/`）

| 他说 | 它回 |
| --- | --- |
| `im 57` | `57。那你现在主要在忙什么？` |
| `typing` | `行。那你一般几点睡、几点起？什么时候最清醒？` |
| `life`（问他在意什么） | `这个答案够大，我不追问了。` |
| `donot forget me`（问红线） | `不会忘。这句我记下了。` |
| `it seems that you are a bit cool` | `刚才那几轮我确实在填表，问得像查户口。现在没事了。` |

七分钟五问，**每一轮都在换题**。他把最重的一句给了红线那一格（"别忘了我"），
系统把它写进 `USER.md` 的 `[红线] 别忘了他` —— 然后这一轮就结束了。
**「这句我记下了」说完，对话没有停在它上面一秒。**

### 2026-11-06 12:20（`~/.cache/hundun-agent/session-20261106-1220.json`）

开场又是「晚上好。怎么称呼你？」——他得说「您好 我们又见面了 我是芜柒」。
然后：

| 他说 | 它回 |
| --- | --- |
| `我是一个失败的程序员` | `「失败」这个词有点重，我先不接这个词。` |
| `写java的 被ai打到了` | `Java 这块这两年确实被挤得厉害…你一般几点睡？` |
| `冷` | `是我问得像在填表了。不问了。` |
| `你好冷` | `刚才那几个问题问得像在填表，是我不好。` |

**「这个词有点重，我先不接这个词」正是 SOUL 里明令禁止的那句**
（`life.js:213`：「怎么这么说自己」比「这个词有点重」暖）。禁令写着，模型照样说，
因为禁令给的是「别说这个」，没给「那说什么」——它手里没有素材。

### 2026-11-11 13:54（当前 `~/life/`）

四轮仪式：`芜柒` → `我是一个失败的程序员` → `程序员` → `活着`。
`USER.md` 落成三行：

```
[称呼] 芜柒
[在做] 程序员
[愿望] 活着
```

馄饨的第一句是 **「这话是今天哪件事砸出来的？」**

三个问题叠在这一句上：

- 它是**追问原因**，而 SOUL 写着「他累了、垮了、在骂自己：这一轮只接住…不分析原因」（`life.js:199`）；
- 同一条 SOUL 的下一段又写「不反驳、不附和、不纠正，**接着问那件事**」（`life.js:204`）——
  **同一份文件对同一句输入给了两个相反的动作**，模型选了能给动作的那个；
- 它的上下文里，「我是一个失败的程序员」来自**仪式第四格**，档案例只留下「程序员」，
  情绪那一半被抽取裁掉了。它知道事实，不知道分量。

`活着` 被当成「愿望」收下、归档、进下一轮提示词，然后仪式关门。
**一个正常人听到「活着」不会再问下一格。这是全篇最硬的一处冷。**

### 三次对话的共同形状

不是措辞问题，是**选择问题**：每一轮它都回答了「这句话对应哪个字段」，
没有一次回答「他说这句话是什么意思」。

## 2. 它现在是怎么运转的

```
仪式（BOOTSTRAP 在）                主程序（BOOTSTRAP 删掉）
─────────────────────              ─────────────────────────
固定话术表 RITUAL_SLOTS             buildSystemPrompt() 8116 字符
  ↓ 模型只判「这格填了没」             ├ Interaction Style 14 行
  ↓ 代码写 USER.md                   ├ Execution Bias / Promised Work
  ↓ 代码把原话拷进当天日记            ├ Runtime + 「他」三条
  ↓ 交接摘要（一轮用完即弃）           ├ Project Context 六份文件全文
                                    ├ 今天/昨天日记 + 召回
                                    ├ Care（5 条禁令）
                                    ├ Memory 块协议 39 行
                                    └ Output（8 条禁令）
                                          ↓
                                    DeepSeek V4.1 Flash
                                          ↓
                              回复 + <memory> 等五种块
                                          ↓
                          blocks.js 解析 → 写文件 → search 索引
```

模块分工是清楚的：`paths`（身份目录）→`life`（文件与模板）→`conversation`（会话与压缩）
→`llm`/`models`（模型链）→`schedule`/`dream`（开口与折叠）→`index`（IPC/窗口）。

**架构本身没有走形**：文件是唯一事实来源、索引可重建、代次防串味、仪式与主程序两份提示词，
这些都在，测试 784 项全过。问题不在骨架，在骨架里装的**内容密度**。

## 3. 四个漏温点

### 3.1 入口：仪式把所有输入当字段

`RITUAL_SLOTS`（`life.js:2682`）是四格表：称呼／身份／愿望／红线。
判据只有「填上了／没填上」，**没有「这句话不对劲」这一档**。
于是：

- `活着` → 写进「愿望」，继续下一格；
- `我是一个失败的程序员` → 抽出「程序员」，情绪丢掉；
- 命中的是「三个主题 + 必须有称呼」就收尾（`bootstrapDone`），**红线那格从没被问到**
  （今天的 `USER.md` 里没有红线，证明走的就是这条路）。

设计意图是清楚的（D113/D115：他要机器感，可见的每个字都写死）。
但代价现在显形了：**仪式是他对这个产品的第一印象，而第一印象是一张表。**
后面所有「暖」的规则，都在对抗这张表留下的印象。

### 3.2 档案：只有标签，没有事

| 文件 | 实际内容 |
| --- | --- |
| `USER.md`「关于他」 | 3 条：称呼／在做／愿望 |
| `USER.md`「他在意什么」 | 空 |
| `USER.md`「要求」 | 空 |
| `MEMORY.md` 六节 | **全空**（关于你／你的模式／进行中的事／红线／我们之间／按天记录） |
| `memory/2026-11-11.md` | 1 行：`13:54 他说：我是一个失败的程序员` |
| `chat/` | 5 行原话（只写不读） |

那唯一一行日记是**代码抄的原话**（`appendDiary`，`life.js:1751`），不是判断。
`appendDiary` 还有一条 `length < 4` 的丢弃（`life.js:1754`）：`芜柒`（2 字）、
`程序员`（3 字）、`活着`（2 字）全被丢掉，只留下最长的那句。

而「模型写判断」这条路（`<memory>` 块）在三次真实会话、约 30 轮里**一条都没发生**。
`memoryRulesBlock()` 用 39 行讲块格式，讲得很细；模型不写。
结果：**它的记忆里没有一个「事」，只有属性。** 属性说不了话，事才能说话。

> openclaw 的日记是模型用文件工具写的，写一次有一次工具回执。
> 我们的模型没有工具，只能靠代码兜底，而代码只会抄。

### 3.3 提示词：一份用「不」写成的性格

实测 `buildPrompt()`（当前身份，真数据）：**8116 字符，41 个 `##` 小节，268 个非空行**。

- 含「不」的行：**113 / 268**
- 「不」字出现：**200 次**；「别」：**31 次**
- 「接住」出现在 **9 行**里（Interaction Style、SOUL、Care、Output 各说一遍）

对照 openclaw 的 `GPT5_FRIENDLY_CHAT_PROMPT_OVERLAY`：**9 行，约 600 字符，全是正向祈使句**。
我们那一节是 **14 行，几乎每行带一个反例**（「『这个词有点重』是站在外面评价」「不把球推回去」
「不道歉退场」）。

这不是审美问题。**规则是按事故报告写的**：每一条都对应一次真机翻车（D092–D108 的记录都在注释里）。
于是提示词读起来像一份事故复盘，而不是一个人的性格。模型在**查清单**，不在**做人**。
这句话项目自己早写过（`life.js:3019` 注释），但清单还在变长。

更麻烦的是**规则互相打架**，而且是同一节里打：

| 位置 | 说的 | 冲突 |
| --- | --- | --- |
| `life.js:199` | 他骂自己时「只接住，不分析原因」 | ← |
| `life.js:204` | 他骂自己时「**接着问那件事**」 | → 这就是「哪件事砸出来的」的来源 |
| `life.js:3042` | 「别把『接一句→判断→问题』当固定骨架」 | ← |
| `life.js:232` + `Output` | 「两到三句」「一次只问一件」「短句」 | → 每轮都长成那个骨架 |
| `SOUL:219` | 「安慰说的是他的状态，不是他的作息」 | ← |
| `Care` | 「不报时间差，不说『上次』『那天』」 | → 它永远无法说出「你上周说过」 |

**最后一行是最贵的**：为了修一个日期算错的 bug（把一小时前说成"昨天"），
把「提起过去」这个能力整条禁掉了。而「提起过去」正是让人觉得"它记得我"的唯一动作。
正确修法是算对日期，不是禁止回忆。

### 3.4 出口：记得，但不许说

即使档案里有东西，规则也不让它说：

- 有了具体旧事时，`Execution Bias` 写着「**他难受的时候，判断留在心里，不进句子**」（`life.js:3054`）；
- `Output` 写着「他累着、垮着的时候，判断收进语气里，**不摆证据**」（`life.js:3200`）；
- `Care` 写着「不报时间差」「不念文件名」「不说『根据我的记忆』」。

三条都对，合起来的效果是：**他最难受的时候，它被禁止使用唯一能证明"我记得你"的素材。**
于是只剩「我在这儿」「你想说的时候我在」——正确，但没有体温。

探针 C 组验证了这一点：给它三条具体旧事，回复反而更短更冷（31 字），
因为它按规则把旧事收起来了。

### 3.5 开口权：默认全关

`judge()`（`schedule.js:333`）四道闸，默认值分别是：

```
disturb.on      = false   → reason: 'off'
disturb.windows = []      → reason: 'noWindow'
disturb.dailyLimit = 0    → reason: 'noLimit'
```

**三道闸全关 = 它永远不会先开口。** 这是 D0xx「不预设数值」红线的正确执行，
但它意味着「到点会问你一句」这个能力，在没配置之前**等于不存在**。
`COMMITMENTS.md`、`OPEN.md` 也是空的，所以主动那条链上**一个可说的素材都没有**。

今天的体验因此是纯反应式：他不说话，屏幕上就永远没有第二句。

### 3.6 模型档位

`config.json` 现在是 `deepseek-v4-1-flash`（中转）。同一条提示词换 `deepseek-v4-pro`：

```
Flash : 我不太信这句。今天哪件事让你这么想的。        （21 字正文）
Pro   : 好。那先不说了，我在这头。你那个「失败」，我没法替你摘掉，
        但今晚它要是压得你喘不上气，就搁我这一会儿。  （158 字）
```

差一个档，暖度差一截。`06-OPENCLAW-PORT.md` 末尾自己写过：
「它的人格提示词从来没有在 DeepSeek 上调过，搬词过来没有基准可比」——这句话是对的，
而它同时也说明：**我们现在是在一个没校准过的底座上，用规则硬掰语气。**

## 4. 对照探针（同模型、同输入、只改提示词）

`temp=0.7`，`deepseek-v4-1-flash`，除注明外均一组一次。

| 组 | 条件 | `我是一个失败的程序员` | `嗯`（承接上一轮） |
| --- | --- | --- | --- |
| A | 当前完整提示词（8116 字符） | 我不太信这句。今天哪件事让你这么想的。（+`<memory>` 块） | 行，那就不问是哪件了。只是这句我不接。你要是这会儿不想说，就在这儿待着也行，不用有话说。 |
| B | 砍掉 Interaction Style／Execution Bias／Care／Output／记忆规则，只留文件 | **「失败」这词太重了…是今天哪个坎没过，还是攒了一阵子了？** | **「嗯」这一声，听着不像没事。…能说出「失败」的人，通常是还在往前走、只是走得太累的那种，真放弃的人不这么说话。你想说的时候，我在这儿。** |
| C | A + 三条具体旧记忆 | 这话听着不像随口说的。今天是有哪件事撞上来了？（31 字，**没用旧事**） | 那就先搁这儿，不用急着说清。我这儿不评分。 |
| D | C + 放开「难受时不许举证」与「不报时间差」 | 「失败」这词从你嘴里出来，说得太干脆了…今天撞上什么了？ | 这话我不跟着认。今天还有非交不可的活没有？ |

三条读法：

1. **B 组最暖，而 B 组是规则最少的一组。** 它那一句「真放弃的人不这么说话」直接违反
   SOUL 的「不反驳、不附和、不纠正」——但它是六条里唯一一句让人觉得**对面有人在**的话。
   「不反驳」这条规则的初衷（不在他的感受上辩论）是对的，代价是把最有力的动作禁掉了。
2. **C 组证明：给素材也没用，规则不让用。** 三条旧事在上下文里，回复一个字没碰。
3. **D 组只改了两句，语气立刻变硬也变近**（「这话我不跟着认」）——说明调规则是有效的，
   但方向不该是继续加条款，而是**把禁令换成条件**。

> 局限：每组一次，温差不排除采样噪声；样本是他一个人、一个模型。
> 但 A/C 与 B/D 的差别在「有没有一句只属于这段关系的话」上，这个差别不受采样影响。

## 5. 与 openclaw 的差距（按「暖从哪来」排序）

| 暖的来源 | openclaw（阿恒） | 馄饨现在 | 性质 |
| --- | --- | --- | --- |
| **共同经历的具体事** | 日记由模型写，一条一次工具回执；MEMORY.md 是年为单位的事实堆积 | 日记是代码抄的原话；MEMORY.md 六节全空 | **缺机制**：没有工具，块协议靠自觉 |

| **人格的写法** | SOUL 1888 字符，**没有一条语气规则**；暖来自内容 | SOUL 2600 字符全是语气规则，另有 Interaction Style／Care／Output 各说一遍 | 方向反了 |
| **上下文规模** | 3.5 万字符，90% 是工具定义 | 8116 字符，约 60% 是规则与禁令 | 密度结构不同，不是好坏 |

| **模型** | GPT-5/Claude 级 | DeepSeek V4.1 Flash | 差档，且没校准过 |

一句话：**openclaw 的暖是"它做了什么"的副产品，馄饨的暖被写成了"它该怎么说话"的任务。**
任务会被执行，副产品不会。

## 6. 缺陷清单

### P0（直接影响"它是不是在听"）

1. **仪式回答被写进日记** — `conversation.js:420` 在 `ritualTurn` 里调 `life.appendDiary(text)`。
   表单碎片变成当天唯一的日记，而模型判断一条没有。
2. **档案抽取会裁掉情绪** — `我在做：程序员` 来自「我是一个失败的程序员」；
   `愿望：活着` 是四格表硬塞（`life.js:2702` 的 `hint` 是「他希望发生的事」）。
   结果是它拿到了事实、丢掉了分量，且没有任何标记提示这条是重的。
3. **历史 48 条硬截断，压缩永不触发** — `conversation.js:597` 取 `slice(-48)`，
   而 `maybeCompact` 的门槛是 `contextWindow × 0.6`（1M → 60 万 token，`conversation.js:350`）。
   长对话里早段**静默掉线**，没有摘要、没有提示。这是"它怎么又不记得了"的第二个来源。

### P1

4. **`SOUL_HISTORY` 少了当前这一版** — `life.js:442` 只到 `SOUL_V7`，
   而现在出厂的是 D117 那一版。下次改 `TPL_SOUL` 时，所有存量机器的 `SOUL.md`
   **逐字比对不上 → 静默不升级**。这个坑已经踩过两次（V6、1410），第三次在前方。
5. **开场那一轮不进日记兜底** — `__hello__` 是 internal，`repairIfNeeded` 被
   `!hooks.internal` 挡住。仪式后的第一句话永远不在当天记录里。
6. **`.session.json` 的首条是 assistant** — internal 开场不 push user，
   文件里的 `history` 从它自己的话开始。接续时模型看到自己一句独白，没有对应的提问。
7. **召回基本恒空** — 语料 11 行，门槛要求「两个不同词命中」（D107 改的，方向对），
   在个位数语料上等于关掉。`search.rebuild` 日志确认：`索引就绪：11 条`。
